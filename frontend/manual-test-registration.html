Manual Registration Status Test

This page is for manually testing the registration status functionality.

Test Steps:

  1. Navigate to http://localhost:3000/register
  2. Check browser console for API call to /api/v1/auth/registration
  3. Verify one of the following:
    • If backend is running with registration enabled: Registration form should appear
    • If backend is running with registration disabled: "Registration Disabled" message should appear
    • If backend is NOT running: Error handling should show "Registration Disabled" (fail-safe default)

Expected Behavior:

  • ✅ Shows loading spinner while checking registration status
  • ✅ Hides form fields when registration is disabled
  • ✅ Shows "Back to Sign In" button when disabled
  • ✅ Caches the registration status (only one API call)
  • ✅ Login page hides "Sign up" link when registration is disabled

Get Clerk authentication running on your LeafLock instance in just 5 minutes with advanced features!

## Prerequisites

- LeafLock instance running locally or deployed
- Node.js 18+ and pnpm installed
- Basic terminal/command line knowledge

## 🚀 5-Minute Setup

<Steps>

1. **Get Clerk Keys**
   
   Go to [Clerk Dashboard](https://dashboard.clerk.com) and:
   
   - Sign up for a free account
   - Click "Create Application"
   - Name it "LeafLock" 
   - Select "React" as framework
   - Go to "API Keys" and copy both keys

2. **Configure Environment**
   
   Copy the example environment file:
   ```bash
   cp .env.example .env
   ```
   
   Add your Clerk keys to `.env`:
   ```bash
   # Clerk Authentication
   CLERK_PUBLISHABLE_KEY=pk_test_your_key_here
   CLERK_SECRET_KEY=sk_test_your_key_here
   VITE_CLERK_PUBLISHABLE_KEY=pk_test_your_key_here
   
   # Enable registration for testing
   VITE_ENABLE_REGISTRATION=true
   ```

3. **Start the Application**
   
   Use the automated setup script:
   ```bash
   ./scripts/setup-clerk-dev.sh
   ```
   
   Or start manually:
   ```bash
   # Start the full stack
   make up
   
   # Or start frontend separately
   cd frontend && pnpm dev
   ```

4. **Test Authentication**
   
   Open your browser and navigate to:
   - **Login**: http://localhost:3000/login
   - **Register**: http://localhost:3000/register
   
   Try creating a new account or signing in!

</Steps>

### Social Login Configuration

Enable social logins through Clerk dashboard:

<Tabs>
  <TabItem label="Google OAuth">
1. Go to Clerk Dashboard → Your App → Social Connections
2. Click "Add Connection" → Google
3. Follow Google's OAuth setup guide
4. Add Client ID and Client Secret
5. Configure redirect URI: `https://yourdomain.com/sso-callback/google`
6. Enable for your application
  </TabItem>
  
  <TabItem label="GitHub OAuth">
1. Go to Clerk Dashboard → Your App → Social Connections
2. Click "Add Connection" → GitHub
3. Create GitHub OAuth App
4. Add Client ID and Client Secret
5. Configure callback URL
6. Enable for your application
  </TabItem>
  
  <TabItem label="Microsoft/Azure">
1. Go to Clerk Dashboard → Your App → Social Connections
2. Click "Add Connection" → Microsoft
3. Set up Azure AD application
4. Add Application ID and Secret
5. Configure redirect URIs
6. Enable for your application
  </TabItem>
</Tabs>

### Multi-Factor Authentication Setup

Enable advanced MFA features:

1. **Go to Clerk Dashboard** → Your App → Email, Phone, Username
2. **Enable 2-Step Verification**
3. **Configure MFA Methods**:
   - Authenticator applications (TOTP)
   - SMS verification
   - Backup codes
   - Email codes
4. **Set MFA Policy**:
   - Optional (recommended for migration)
   - Required for specific roles
   - Required for all users

### Organization Management

If you need multi-tenant support:

1. **Enable Organizations** in Clerk Dashboard
2. **Configure Organization Settings**:
   ```tsx
   // In your App.tsx
   <ClerkProvider
     // ... other props
     organizationSettings={{
       maxAllowedMemberships: 100,
       adminDeleteEnabled: true,
       domains: {
         enrollmentModes: ['manual_invitation'],
         defaultRole: 'basic_member'
       }
     }}
   >
   ```

3. **Use Organization Components**:
   ```tsx
   import { OrganizationSwitcher, OrganizationProfile } from '@clerk/clerk-react'
   
   // Organization switcher
   <OrganizationSwitcher />
   
   // Organization profile management
   <OrganizationProfile />
   ```

## 🔧 Common Issues & Advanced Solutions

### Issue: "Social login not working"
**Advanced Solution**:
1. Check redirect URI configuration
2. Verify OAuth app settings
3. Test with different social providers
4. Check CORS settings for OAuth callbacks

### Issue: "MFA not prompting"
**Advanced Solution**:
1. Check MFA policy in Clerk dashboard
2. Verify user has verified email/phone
3. Test with different MFA methods
4. Check MFA rate limiting

### Issue: "Organization features not available"
**Advanced Solution**:
1. Enable organizations in Clerk dashboard
2. Check organization limits
3. Verify user permissions
4. Test organization creation flow

### Issue: "Session management not working"
**Advanced Solution**:
1. Check session token validation
2. Verify Clerk session endpoints
3. Test session revocation
4. Monitor session creation/deletion

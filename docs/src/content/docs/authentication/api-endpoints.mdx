## Error Codes

All errors include structured `code` field for client-side handling:

| Code | HTTP Status | Description | Handling |
|------|-------------|-------------|----------|
| `INVALID_CREDENTIALS` | 401 | Wrong email/password | Show error, allow retry |
| `ACCOUNT_LOCKED` | 403 | 5+ failed attempts | Show 15min lockout message |
| `MFA_REQUIRED` | 200 | MFA verification needed | Redirect to MFA input |
| `INVALID_MFA_CODE` | 401 | Wrong TOTP/backup code | Show error, allow retry |
| `INVALID_TOKEN` | 401 | Invalid/missing JWT | Redirect to login |
| `EXPIRED_TOKEN` | 401 | Token expired | Redirect to login |
| `USER_NOT_FOUND` | 404 | User doesn't exist | Generic error (security) |
| `EMAIL_EXISTS` | 409 | Duplicate registration | Show "email taken" |
| `VALIDATION_FAILED` | 400 | Input validation error | Show field-specific errors |
| `REGISTRATION_DISABLED` | 403 | Registration not allowed | Show "registration closed" |

**Implementation**: `backend/auth/models.go:97-110`

## Rate Limiting

Redis-based distributed rate limiting using fixed window algorithm:

| Endpoint Group | Limit | Window | Key Format |
|----------------|-------|--------|------------|
| Login | 10 requests | 5 minutes | `limiter:{ip}:/api/v1/auth/login` |
| MFA Verify | 10 requests | 5 minutes | `limiter:{ip}:/api/v1/auth/mfa/verify` |
| MFA Setup/Enable/Disable | 10 requests | 5 minutes | `limiter:{ip}:/api/v1/auth/mfa/*` |
| Password Reset | 10 requests | 5 minutes | `limiter:{ip}:/api/v1/auth/password/*` |

**Rate Limit Response (429)**:
```json
{
  "error": "Too many requests, please try again later"
}
```

**Implementation**: `backend/middleware/rate_limit.go:45`
**IP Detection**: `backend/utils/network.go:34` (supports X-Forwarded-For, CF-Connecting-IP)

## JWT Token Details

**Token Structure**:
- Signing: HS256 (HMAC-SHA256)
- Expiration: 24 hours
- Claims: `user_id`, `is_admin`, `exp`

**Storage**:
- Redis key: `session:<token_hash>` (Argon2id hash)
- Session data: XChaCha20-Poly1305 encrypted
- Contains: user_id, ip_address, user_agent, mfa_verified, created_at

**Validation Flow**:
1. Extract from `Authorization: Bearer <token>` header
2. Verify JWT signature and expiration
3. Check session exists in Redis
4. Decrypt session data
5. Set `user_id`, `is_admin` in Fiber context

**Implementation**: `backend/auth/service.go:89` (GenerateJWT), `backend/auth/service.go:137` (ValidateJWT)

## Integration Example

<Code code={`// Complete login flow with MFA
async function loginWithMFA(email, password) {
  // Step 1: Initial login
  const loginRes = await fetch('/api/v1/auth/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ email, password })
  })

  const loginData = await loginRes.json()

  if (loginRes.status === 401 && loginData.code === 'INVALID_CREDENTIALS') {
    throw new Error('Invalid email or password')
  }

  if (loginRes.status === 403 && loginData.code === 'ACCOUNT_LOCKED') {
    throw new Error('Account locked. Try again in 15 minutes.')
  }

  // Step 2: Handle MFA if required
  if (loginData.mfa_required) {
    const mfaCode = await promptUserForMfaCode()

    const mfaRes = await fetch('/api/v1/auth/mfa/verify', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        session_token: loginData.session_token,
        code: mfaCode
      })
    })

    if (!mfaRes.ok) {
      const error = await mfaRes.json()
      throw new Error(error.error)
    }

    const { token, user_id, workspace_id } = await mfaRes.json()
    return { token, user_id, workspace_id }
  }

  // No MFA required
  return loginData
}

// Setup MFA
async function setupMFA(jwtToken) {
  // Step 1: Begin setup (get QR code)
  const setupRes = await fetch('/api/v1/auth/mfa/setup', {
    method: 'POST',
    headers: { 'Authorization': \`Bearer \${jwtToken}\` }
  })

  const { secret, qr_code_url } = await setupRes.json()

  // Show QR code to user
  displayQRCode(qr_code_url)

  // Step 2: User scans QR, enters verification code
  const verificationCode = await promptUserForCode()

  // Step 3: Enable MFA
  const enableRes = await fetch('/api/v1/auth/mfa/enable', {
    method: 'POST',
    headers: {
      'Authorization': \`Bearer \${jwtToken}\`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({ secret, code: verificationCode })
  })

  const { backup_codes } = await enableRes.json()

  // IMPORTANT: Show backup codes to user (one-time display)
  displayBackupCodes(backup_codes)
}

    method: 'POST',

## Security Notes

**Encryption**:
- MFA secrets: XChaCha20-Poly1305 with `SERVER_ENCRYPTION_KEY`
- Sessions: XChaCha20-Poly1305 encrypted in Redis
- Passwords: Argon2id (3 iterations, 64MB memory, 4 threads)
- Backup codes: Argon2id with deterministic salt (for verification)

**Constant-Time Operations**:
- TOTP code comparison: `backend/auth/mfa.go:65`
- Backup code comparison: `backend/auth/mfa.go:124`
- Prevents timing attacks

**Token Security**:
- Reset tokens: SHA-256 hashed, 1-hour expiration, single-use
- MFA sessions: 5-minute expiration, deleted after verification
- JWT tokens: 24-hour expiration, Redis-backed validation

**Account Protection**:
- Failed attempts tracked per user
- Auto-lock after 5 failures (15min duration)
- Counter resets on successful login
- All sessions invalidated on password change

**Implementation Files**:
- Crypto service: `backend/crypto/crypto.go`
- Session management: `backend/auth/session.go`
- Password handling: `backend/auth/password.go`

LeafLock implements RFC 6238 TOTP multi-factor authentication with encrypted secret storage and Argon2id-hashed backup codes.

## Implementation Details

**TOTP Configuration** (`backend/auth/mfa.go:35`):
- Algorithm: SHA-1 (RFC 6238 standard)
- Time step: 30 seconds
- Code length: 6 digits
- Window: ±30 seconds (90-second validity)
- Secret storage: XChaCha20-Poly1305 encrypted in `mfa_secret_encrypted` column

**Backup Codes** (`backend/auth/mfa.go:89`):
- Count: 10 codes per user
- Format: 12 characters (XXXX-XXXX-XXXX)
- Storage: Argon2id hashed with deterministic salt
- Usage: Single-use, constant-time comparison
- Regeneration: Requires password confirmation

**Rate Limiting** (`backend/middleware/rate_limit.go:45`):
- MFA verification: 10 requests per 5 minutes (IP-based)
- MFA setup/enable/disable: 10 requests per 5 minutes
- Implementation: Redis fixed window algorithm
- Key format: `limiter:{ip}:/api/v1/auth/mfa/*`

**Security Features**:
- Constant-time code comparison (prevents timing attacks)
- Account lockout: 5 failed login attempts = 15-minute lock
- MFA session tokens: 5-minute expiration
- Audit logging: All MFA events tracked in `audit_log` table

## Endpoints

- `POST /api/v1/auth/mfa/setup` - Generate TOTP secret and QR code
- `POST /api/v1/auth/mfa/enable` - Activate MFA (returns backup codes)
- `POST /api/v1/auth/mfa/verify` - Verify TOTP/backup code during login
- `POST /api/v1/auth/mfa/disable` - Deactivate MFA
- `GET /api/v1/auth/mfa/status` - Check MFA status and remaining codes
- `POST /api/v1/auth/mfa/backup-codes/regenerate` - Generate new backup codes

Full API reference: [/authentication/api-endpoints](/authentication/api-endpoints)

## Database Schema

**Users table columns** (`backend/database/schema.go:22-25`):
```sql
mfa_enabled BOOLEAN DEFAULT false
mfa_secret_encrypted BYTEA
mfa_backup_codes BYTEA[]        -- Argon2id hashes (10 total)
mfa_backup_codes_used BYTEA[]   -- Hashes of used codes
```

**Audit log events**:
- `mfa.enabled` / `mfa.disabled`
- `mfa.verification_success` / `mfa.verification_failed`
- `mfa.backup_code_used` / `mfa.backup_code_failed`
- `mfa.backup_codes_regenerated`

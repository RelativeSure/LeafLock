# MFA Backup Recovery Codes (Clerk)

Backup codes are emergency access codes that allow you to log in when you don't have access to your primary MFA method. Clerk provides enterprise-grade backup code management with enhanced security features.

## What Are Backup Codes?

- **One-time use codes** that bypass MFA authentication
- Generated automatically when you enable MFA with Clerk
- **8-digit numeric codes** (Clerk's standard format)
- **10 codes** provided by default
- Managed securely through Clerk's infrastructure
- Synchronized across all Clerk-enabled applications

## When to Use Backup Codes

Use a backup code when you:
- Lost your phone with your authenticator app
- Can't receive SMS verification codes
- Your authenticator device is broken or unavailable
- You're traveling and don't have access to your primary device
- Need emergency access to your account

## How to Use a Backup Code

1. Go to the LeafLock login page
2. Enter your email and password
3. On the MFA verification screen, click **Try another method**
4. Select **Backup code**
5. Enter one of your saved backup codes
6. Click **Continue**

**Important**: Each code works only once and is then permanently invalidated.

## Clerk's Backup Code Features

### Automatic Management
- **Secure Generation**: Cryptographically secure random codes
- **Cloud Sync**: Available across all your Clerk-enabled apps
- **Automatic Invalidation**: Used codes are immediately marked invalid
- **Real-time Updates**: Status updates across all devices

### Enhanced Security
- **Rate Limiting**: Prevents brute force attacks on backup codes
- **Audit Trail**: All backup code usage is logged
- **Device Recognition**: Detects suspicious usage patterns
- **Time Limits**: Codes expire if not used within reasonable timeframe

## Accessing Your Backup Codes

### During Initial MFA Setup:
1. Clerk displays your backup codes after MFA verification
2. **Save them immediately** - this is the only time they're shown
3. Download as text file or copy to clipboard
4. Store them securely before continuing

### Viewing Backup Code Status:
1. Log in to LeafLock
2. Go to **Profile** → **Security** → **Two-Factor Authentication**
3. View:
   - Total backup codes: 10
   - Remaining codes: (shows current count)
   - Last regenerated: (timestamp)

**Note**: You cannot view the actual codes after initial setup for security reasons.

## Storing Backup Codes Securely

### Recommended Storage Methods

1. **Password Manager** (Best option)
   - Store in 1Password, Bitwarden, LastPass, etc.
   - Automatically encrypted and backed up
   - Easy to access when needed
   - Many support secure sharing with trusted contacts

2. **Encrypted Note Apps**
   - Apple Notes (with encryption)
   - Standard Notes
   - Joplin
   - Obsidian with encryption plugins

3. **Physical Storage**
   - Write codes on paper
   - Store in a safe or lockbox
   - Keep in multiple secure locations
   - Consider fireproof/waterproof storage

4. **Encrypted Cloud Storage**
   - VeraCrypt encrypted containers
   - Cryptomator encrypted folders
   - Boxcryptor encrypted files

### Not Recommended

- Plain text files on your computer
- Regular email or unencrypted messaging
- Unencrypted cloud storage (Google Drive, Dropbox)
- Shared documents or notes
- Photos or screenshots on your phone
- Social media or public platforms

## Managing Your Backup Codes

### Regenerating Backup Codes

You can generate new backup codes at any time:

1. Go to **Profile** → **Security** → **Two-Factor Authentication**
2. Click **Regenerate Backup Codes**
3. Verify your identity (may require MFA or password)
4. New codes are generated and old ones are invalidated
5. **Download or copy** the new codes immediately
6. Store them securely and delete old copies

**Warning**: Regenerating codes invalidates ALL previous codes, including unused ones.

### When to Regenerate Codes

Consider generating new backup codes when:
- You've used more than 5 of your 10 codes
- You suspect codes may have been compromised
- You want to refresh your security regularly
- You've shared a code (not recommended)
- You need to update your storage method

## Backup Code Recovery Scenarios

### Scenario 1: Lost Phone

1. Go to LeafLock login page
2. Enter email and password
3. Click **Try another method**
4. Select **Backup code**
5. Enter one of your saved backup codes

   - Go to security settings
   - Update your MFA methods
   - Generate new backup codes
   - Store them securely

### Scenario 2: Traveling Without Primary Device

1. Use backup codes for login
2. After trip, regenerate codes for security
3. Update MFA setup on new/travel device if needed

### Scenario 3: Running Low on Codes

1. Check remaining codes in security settings
2. If fewer than 3 remain, regenerate immediately
3. Store new codes securely
4. Delete old copies

## Frequently Asked Questions

### Can I view my backup codes after initial setup?
No. For security reasons, Clerk does not display backup codes after the initial setup. You must save them when first generated or regenerate new ones.

### How many times can I regenerate codes?
Unlimited. You can regenerate backup codes as many times as needed through your security settings.

### Do old codes work after regenerating?
No. Regenerating codes immediately invalidates all previous codes across all Clerk-enabled applications.

### Can I have more than 10 backup codes?
Currently, Clerk provides 10 codes by default. This is sufficient for most users and follows security best practices.

### Are backup codes encrypted?
Yes. Clerk encrypts backup codes both in transit and at rest using industry-standard encryption.

### What if I lose all my MFA methods?
Use the account recovery process:
1. Click "Can't access your authentication methods?" on login
2. Follow email verification steps
3. Contact your administrator if additional help is needed

### Can I use the same backup code multiple times?
No. Each backup code can only be used once and is immediately invalidated after use.

## Emergency Recovery

If you've lost access to all MFA methods and backup codes:

1. **Use Account Recovery**:
   - Click "Can't access your authentication methods?"
   - Follow email verification process
   - Complete identity verification

2. **Contact Administrator**:
   - Reach out to your system administrator
   - Provide identity verification
   - Request MFA reset

3. **After Recovery**:
   - Immediately re-enable MFA
   - Generate new backup codes
   - Store them securely
   - Review account security settings

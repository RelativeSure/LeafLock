# Managing Your MFA Settings (Clerk)

This guide covers how to manage your Multi-Factor Authentication (MFA) after you've enabled it with Clerk's enterprise-grade authentication system.

## Understanding Clerk MFA Management

Clerk provides a unified MFA experience across all applications. Changes you make in LeafLock will apply to other Clerk-enabled apps you use.

## Accessing MFA Settings

### Method 1: Through LeafLock Settings
1. Log in to your LeafLock account
2. Click on your **profile icon** in the top navigation
3. Navigate to **Profile** → **Security** → **Two-Factor Authentication**

### Method 2: Through Clerk User Button
1. Click the **User Button** (profile icon) in the navigation
2. Select **Manage account**
3. Navigate to **Security** → **Two-Factor Authentication**

### Method 3: Direct Clerk Portal
1. Visit your [Clerk user portal](https://accounts.clerk.com)
2. Sign in with your credentials
3. Navigate to **Security** settings

## Managing Authentication Methods

Clerk supports multiple authentication methods that you can manage:

### Primary Methods
- **Authenticator App** (TOTP) - Most secure
- **SMS/Text Message** - Convenient backup
- **Email Codes** - Additional backup option

### Backup Methods
- **Backup Codes** - One-time use emergency codes
- **Recovery Phone** - Alternative phone number
- **Trusted Devices** - Device-based authentication

## Adding/Removing Authentication Methods

### Adding a New Method

<Tabs>
  <TabItem label="Authenticator App">
1. Go to **Security** → **Two-Factor Authentication**
2. Click **Add authentication method**
3. Select **Authenticator app**
4. Scan the QR code with your authenticator app
5. Enter the 6-digit verification code
6. Name your device (e.g., "iPhone 14", "Google Pixel")
7. Click **Continue** to complete setup

**Supported Apps:**
- Google Authenticator
- Authy
- 1Password
- Microsoft Authenticator
- Any TOTP-compatible app
  </TabItem>
  
  <TabItem label="SMS/Text Message">
1. Go to **Security** → **Two-Factor Authentication**
2. Click **Add authentication method**
3. Select **Phone number**
4. Enter your phone number with country code
5. Choose **Text message (SMS)**
6. Enter the verification code sent to your phone
7. Click **Continue** to complete setup

**Note:** SMS rates may apply depending on your carrier.
  </TabItem>
  
  <TabItem label="Email Codes">
1. Go to **Security** → **Two-Factor Authentication**
2. Click **Add authentication method**
3. Select **Email codes**
4. Verify your email address
5. Enter the verification code sent to your email
6. Click **Continue** to complete setup

**Note:** Make sure you have access to this email account.
  </TabItem>
</Tabs>

### Removing a Method

1. Go to **Security** → **Two-Factor Authentication**
2. Find the method you want to remove
3. Click **Remove** or the trash icon
4. Verify your identity with another method
5. Confirm the removal

**Important**: You must have at least one backup method enabled. Clerk won't let you remove your last backup method.

## Managing Backup Codes

### Understanding Clerk Backup Codes

- **8-digit numeric codes** (Clerk standard)
- **10 codes** provided automatically
- **One-time use** only
- **Cross-application**: Work across all Clerk-enabled apps
- **Automatically regenerated** when you add/remove MFA methods

### Viewing Backup Code Status

1. Go to **Security** → **Two-Factor Authentication**
2. Look for **Backup codes** section
3. You'll see:
   - **Remaining codes**: Number of unused codes
   - **Total codes**: Always 10
   - **Last regenerated**: When codes were last updated

**Note**: You cannot view the actual codes after initial setup for security reasons.

### When Codes Are Automatically Regenerated

Clerk automatically creates new backup codes when you:
- Add a new authentication method
- Remove an authentication method
- Reset your MFA settings

### Manual Regeneration

If you need new backup codes:

1. Go to **Security** → **Two-Factor Authentication**
2. Find **Backup codes** section
3. Click **Regenerate codes**
4. Verify your identity with an existing method
5. **Save the new codes immediately**
6. Store them securely and delete old copies

**Warning**: This invalidates all previous backup codes.

## Managing Trusted Devices

Clerk remembers devices you've successfully used for MFA:

### Viewing Trusted Devices
1. Go to **Security** → **Trusted devices**
2. See all devices where you're currently logged in
3. View details: device type, browser, location, last active

### Managing Devices
- **Trust this device**: Skip MFA for 30 days on this device
- **Remove device**: Log out and remove from trusted list
- **Remove all devices**: Force logout from everywhere except current session

### Device Security
- **Automatic removal**: Devices are removed after 30 days of inactivity
- **Suspicious activity**: Clerk may remove devices if suspicious login detected
- **Location tracking**: Shows approximate location of device usage

## Disabling MFA

**⚠️ Security Warning**: Disabling MFA reduces your account security significantly. You'll only need your password to sign in.

### When You Might Disable MFA
- Switching to a new primary authentication method
- Troubleshooting authentication issues
- Temporarily for device migration

### How to Disable MFA

1. Go to **Security** → **Two-Factor Authentication**
2. Click **Disable two-factor authentication**
3. Verify your identity using any active method:
   - Enter TOTP code from authenticator app
   - Use SMS verification code
   - Use backup code
   - Use email verification
4. Confirm you understand the security implications
5. Click **Disable** to complete

### What Happens After Disabling

- You can log in with email and password only
- All MFA methods are disabled
- Backup codes are invalidated
- Your account security is reduced
- You'll see security warnings when logging in

### Re-enabling MFA

**Strongly recommended** to re-enable MFA immediately:

1. Go to **Security** → **Two-Factor Authentication**
2. Click **Enable two-factor authentication**
3. Set up your preferred method
4. Save new backup codes

## Switching to a New Device

### Option 1: Multi-Device Setup (Recommended)

Many authenticator apps support multiple devices:

**Authy**: Automatically syncs across devices
**1Password**: Syncs to all your devices
**Microsoft Authenticator**: Cloud backup available

### Option 2: Manual Transfer

If your app doesn't support multi-device sync:

1. **Before switching devices**:
   - Ensure you have working backup codes
   - Log into LeafLock on a computer
   
2. **On new device**:
   - Install authenticator app
   - Go to LeafLock security settings
   - Add new device as authentication method
   - Remove old device after verification

### Option 3: Temporary Disable/Re-enable

1. Use backup codes to log in on new device
2. Disable MFA temporarily
3. Re-enable MFA with new device
4. Generate and save new backup codes

## Advanced MFA Features

### Custom MFA Rules

Clerk supports custom MFA policies:

- **Conditional MFA**: Only require for sensitive operations
- **Risk-based MFA**: Trigger based on login patterns
- **Location-based**: Different requirements by geographic location

### MFA for Organizations

If your LeafLock instance uses Clerk Organizations:

- **Organization-level MFA**: Required for all org members
- **Role-based requirements**: Different MFA for different roles
- **Admin enforcement**: Organization admins can require MFA

## Security Monitoring

### Viewing Security Activity

1. Go to **Security** → **Security activity**
2. See recent login attempts and security events
3. View:
   - Successful logins
   - Failed login attempts
   - MFA usage
   - Device additions/removals
   - Password changes

### Security Alerts

Clerk automatically alerts you about:
- Login from new device/location
- Multiple failed login attempts
- MFA method changes
- Password changes
- Suspicious activity patterns

### Responding to Security Alerts

If you receive a security alert:
1. **Verify the activity**: Check if it was you
2. **If legitimate**: No action needed
3. **If suspicious**:
   - Change your password immediately
   - Review and remove unfamiliar devices
   - Regenerate backup codes
   - Contact your administrator

## Troubleshooting Common Issues

### "Can't access your authentication methods?"

**Use account recovery**:
1. Click "Can't access your authentication methods?" on login
2. Follow email verification process
3. Complete identity verification
4. Set up new MFA methods

### Time synchronization issues

**Symptoms**: TOTP codes don't work
**Solutions**:
- Enable automatic date/time on your device
- Most authenticator apps handle this automatically
- Clerk allows reasonable time drift

### Lost access to all MFA methods

**Recovery options**:
1. Use account recovery process
2. Contact your system administrator
3. Use emergency contact if configured
4. Verify identity through alternative channels

### Backup codes not working

**Check**:
- Entering code correctly (no typos)
- Code hasn't been used before
- You're using current codes (not old ones)
- Try a different code

### SMS codes not arriving

**Check**:
- Phone has signal
- Correct phone number in profile
- Not in airplane mode
- Carrier supports SMS
- Try alternative method

## Best Practices

### Security Recommendations

✅ **Do**:
- Enable multiple authentication methods
- Keep backup codes in secure password manager
- Use authenticator app as primary method
- Enable security notifications
- Regularly review trusted devices
- Update MFA when switching devices

❌ **Don't**:
- Rely solely on SMS (less secure)
- Share MFA codes with anyone
- Store backup codes in plain text
- Ignore security alerts
- Use the same password across sites
- Disable MFA without immediate re-enabling

### Regular Maintenance

**Monthly**:
- Check security activity log
- Review trusted devices
- Verify contact information

**Quarterly**:
- Regenerate backup codes
- Update recovery information
- Review security settings

**Annually**:
- Audit all authentication methods
- Update emergency contacts
- Review organization security policies

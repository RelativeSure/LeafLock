This guide helps you diagnose and fix common issues with Clerk authentication in LeafLock.

## Quick Diagnostics

Before diving into specific issues, run these quick checks:

```bash title="Quick Health Check"
# Check if Clerk is configured
echo $CLERK_SECRET_KEY | grep -q "sk_" && echo "✅ Clerk configured" || echo "❌ Clerk not configured"

# Check if backend can reach Clerk
curl -s https://api.clerk.com/v1/health | jq -r ".status" || echo "❌ Cannot reach Clerk API"

# Check frontend build
pnpm run typecheck && echo "✅ TypeScript clean" || echo "❌ TypeScript errors"

# Check authentication
pnpm run build && echo "✅ Build successful" || echo "❌ Build failed"
```

## Common Issues

### Configuration Issues

#### "CLERK_SECRET_KEY not found"

<Aside type="tip">
Make sure you have all three Clerk environment variables set:
- `CLERK_PUBLISHABLE_KEY`
- `CLERK_SECRET_KEY` 
- `VITE_CLERK_PUBLISHABLE_KEY`
</Aside>

**Symptoms:**
- Authentication components don't load
- Backend shows "Clerk not configured" warnings
- Frontend shows "Publishable key not found" errors

**Solutions:**

<Tabs>
<TabItem label="Development">
```bash
# Check current environment
cat .env | grep CLERK

# Add missing variables
echo "CLERK_PUBLISHABLE_KEY=pk_test_your_key" >> .env
echo "CLERK_SECRET_KEY=sk_test_your_key" >> .env
echo "VITE_CLERK_PUBLISHABLE_KEY=pk_test_your_key" >> .env

# Restart your development server
make down && make up
```
</TabItem>

<TabItem label="Production">
```bash
# Check your deployment platform
# Add environment variables to your platform:
# - Railway: Dashboard > Variables
# - Vercel: Project Settings > Environment Variables
# - Docker: docker-compose.yml or .env file
# - Kubernetes: ConfigMap or Secret

CLERK_PUBLISHABLE_KEY=pk_live_your_key
CLERK_SECRET_KEY=sk_live_your_key
VITE_CLERK_PUBLISHABLE_KEY=pk_live_your_key
```
</TabItem>
</Tabs>

#### "Invalid Clerk keys"

**Symptoms:**
- "Invalid publishable key" error in browser console
- "Invalid secret key" error in backend logs
- Authentication fails immediately

**Solutions:**

1. **Verify Key Format**
   ```bash
   # Test keys should start with:
   # Publishable: pk_test_ (development) or pk_live_ (production)
   # Secret: sk_test_ (development) or sk_live_ (production)
   
   echo $CLERK_SECRET_KEY | grep -E "^sk_(test|live)_"
   ```

2. **Check Application Environment**
   ```bash
   # Make sure keys match your environment
   # Development keys won't work in production
   # Production keys won't work in development
   ```

3. **Regenerate Keys**
   - Go to [Clerk Dashboard](https://dashboard.clerk.com)
   - Navigate to your application
   - Go to "API Keys"
   - Click "Regenerate" if needed
   - Update your environment variables

**Symptoms:**

- No Authorization header in network requests

```tsx

function MyComponent() {
  const apiClient = useClerkApiClient()
  
  const fetchData = async () => {
    try {
      const data = await apiClient.get('/api/data')
      // Handle data
    } catch (error) {
      console.error('API call failed:', error)
    }
  }
}
```
</TabItem>

<TabItem label="Manual Token Handling">
```tsx
import { useSession } from '@clerk/clerk-react'

function MyComponent() {
  const { getToken } = useSession()
  
  const fetchData = async () => {
    const token = await getToken()
    
    const response = await fetch('/api/data', {
      headers: {
        'Authorization': `Bearer ${token}`,
        'Content-Type': 'application/json',
      },
    })
    
    if (!response.ok) {
      throw new Error(`HTTP ${response.status}: ${response.statusText}`)
    }
    
    return response.json()
  }
}
```
</TabItem>

## Performance Issues

#### "Slow authentication"

**Symptoms:**
- Authentication takes >2 seconds
- Users complain about login speed
- Backend shows slow response times

**Solutions:**

<Tabs>
<TabItem label="Enable Token Caching">
```go
// Implement token caching
type TokenCache struct {
    cache map[string]*CachedToken
    mutex sync.RWMutex
    ttl   time.Duration
}

func (tc *TokenCache) Set(token string, userID uuid.UUID, isAdmin bool) {
    tc.mutex.Lock()
    defer tc.mutex.Unlock()
    
    tc.cache[token] = &CachedToken{
        UserID:    userID,
        IsAdmin:   isAdmin,
        ExpiresAt: time.Now().Add(tc.ttl),
    }
}

func (tc *TokenCache) Get(token string) (uuid.UUID, bool, bool) {
    tc.mutex.RLock()
    defer tc.mutex.RUnlock()
    
    cached, exists := tc.cache[token]
    if !exists || time.Now().After(cached.ExpiresAt) {
        return uuid.Nil, false, false
    }
    
    return cached.UserID, cached.IsAdmin, true
}
```
</TabItem>

<TabItem label="Optimize Database Queries">

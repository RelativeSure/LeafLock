# Multi-Factor Authentication Setup Guide

This guide will help you set up Two-Factor Authentication (2FA/MFA) on your LeafLock account using Clerk's built-in MFA features.

## Prerequisites

- An active LeafLock account with Clerk authentication
- A smartphone or tablet
- An authenticator app installed (see [supported apps](#supported-authenticator-apps))
- Access to your email for verification

## How Clerk MFA Works

LeafLock uses Clerk's enterprise-grade MFA system which provides:

- **Multiple Methods**: TOTP (Time-based One-Time Password), SMS codes, backup codes
- **Automatic Backup**: Cloud-synced across your Clerk-enabled applications  
- **Advanced Security**: Breach detection, rate limiting, device management
- **Easy Recovery**: Multiple recovery options if you lose access

## Step 1: Access Security Settings

1. Log in to your LeafLock account
2. Click on your profile icon in the top navigation
3. Navigate to **Profile** → **Security** → **Two-Factor Authentication**
4. Or use Clerk's user button component which provides direct access

## Step 2: Begin MFA Setup

1. Click the **Enable Two-Factor Authentication** button
2. Clerk will present you with authentication method options:
   - **Authenticator App** (Recommended) - TOTP codes
   - **SMS/Text Message** - Codes sent to your phone
   - **Backup Codes** - One-time use recovery codes

## Step 3: Set Up Authenticator App (Recommended)

### Choose Your Authenticator App:

**Recommended apps:**
- **Google Authenticator** - Simple and widely supported
- **Authy** - Multi-device sync and cloud backup
- **1Password** - Password manager with TOTP support
- **Microsoft Authenticator** - Good for Microsoft ecosystems

### Scan QR Code:

1. Select **Authenticator App** as your method
2. Clerk will display a QR code
3. Open your authenticator app
4. Tap the **+** or **Add** button
5. Select **Scan QR Code**
6. Point your camera at the QR code on screen
7. The app will automatically add a LeafLock entry

### Alternative: Manual Entry

If you can't scan the QR code:

1. In your authenticator app, select **Enter a setup key**
2. Enter the details shown below the QR code:
   - **Account name**: Your email address (pre-filled)
   - **Secret key**: The text code provided
   - **Type of key**: Time-based (TOTP)
3. Save the entry

## Step 4: Verify Your Setup

1. Your authenticator app will display a 6-digit code
2. Enter this code in the verification field on LeafLock
3. Click **Verify & Continue**
4. Clerk will confirm your authenticator is working correctly

## Step 5: Set Up Backup Methods

Clerk will prompt you to set up additional backup methods:

### Backup Codes (Required)

1. Clerk will generate 10 backup recovery codes
2. **Save these codes immediately** - they won't be shown again
3. Store them securely (see [storage recommendations](#backup-code-storage))

### SMS Backup (Optional)

1. Add your phone number for SMS backup codes
2. Verify your phone number with a test code
3. SMS codes will be sent if your authenticator app is unavailable

## Step 6: Complete Setup

1. Review your backup methods
2. Click **Finish Setup**
3. MFA is now enabled on your account

## Testing Your Setup

**Before relying on MFA, test it:**

1. While still logged in, open an incognito/private browser window
2. Try logging in to verify MFA works correctly
3. Test your authenticator app code
4. Test a backup code (remember: each can only be used once)

## Using MFA to Log In

### Normal Login:

1. Enter your email and password
2. You'll be prompted for your MFA code
3. Open your authenticator app
4. Enter the 6-digit code for LeafLock
5. Click **Verify**

### Using Backup Methods:

If you don't have your authenticator app:

1. Click **Try another method** on the MFA screen
2. Choose from:
   - **SMS/Text Message** (if configured)
   - **Backup Code** (one-time use)
   - **Email Code** (if available)
3. Enter the code you receive
4. Click **Verify**

## Backup Code Storage

**Recommended storage locations:**
- Password manager (1Password, Bitwarden, etc.)
- Encrypted note-taking app
- Physical paper in a secure location (safe, lockbox)
- Secure cloud storage with encryption

**Not recommended:**
- Unencrypted text files
- Regular email
- Shared documents
- Screenshots on your phone

## Managing Your MFA Settings

### Adding/Removing Methods:

1. Go to **Profile** → **Security** → **Two-Factor Authentication**
2. Click **Manage Authentication Methods**
3. Add new methods or remove existing ones
4. Verify changes with your current MFA method

### Viewing Active Sessions:

1. Navigate to **Profile** → **Security** → **Active Sessions**
2. See all devices logged into your account
3. Revoke any suspicious sessions
4. Review login history for security

## Recovery Options

If you lose access to your MFA methods:

### Primary Recovery:
1. Use a backup code (each can only be used once)
2. Use SMS backup if configured
3. Use email verification if available

### Account Recovery:
1. Click **Can't access your authentication methods?**
2. Follow the account recovery process
3. Verify your identity through email
4. Contact support if needed

## Security Features

Clerk's MFA includes advanced security:

- **Rate Limiting**: Prevents brute force attacks
- **Device Recognition**: Remembers trusted devices
- **Suspicious Activity Detection**: Alerts for unusual login patterns
- **Automatic Backup**: Syncs across Clerk-enabled applications
- **Time Synchronization**: Handles clock drift automatically

## Troubleshooting

### "Invalid MFA code" error:
- Wait for a new code (codes refresh every 30 seconds)
- Check you're using the correct authenticator app entry
- Ensure your device has accurate time (enable automatic time)
- Try a backup code to verify your account

### Lost authenticator app:
- Use SMS backup codes if configured
- Use backup recovery codes
- Contact support for account recovery

### Can't receive SMS codes:
- Check phone signal and airplane mode
- Verify correct phone number in settings
- Use backup codes or authenticator app

### Time synchronization issues:
- Enable automatic date/time on your device
- Most authenticator apps handle this automatically
- Clerk's system allows for reasonable time drift

## Supported Authenticator Apps

- Google Authenticator

- Microsoft Authenticator
- LastPass Authenticator

**All TOTP-compatible apps work with Clerk.**

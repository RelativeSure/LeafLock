## Overview

This page provides a complete reference of all **38 API endpoints** available in LeafLock, organized by functionality and security requirements.

## Security Summary

### Public Endpoints (8 total)
- User registration and login
- Password reset flow
- MFA verification
- Public announcements
- Public share link access

### Protected Endpoints (29 total)
- All note operations
- User settings and account management
- MFA setup and management
- Share link creation and management

### Admin-Only Endpoints (4 total)
- Announcement management
- User administration
- System configuration

## Quick Reference

**Total Endpoints**: 38
- **Public**: 8 endpoints
- **Protected**: 29 endpoints
- **Admin-Only**: 4 endpoints

**Authentication**: JWT Bearer Token
**Base URL**: `https://leaflock.app/api/v1` (production) or `http://localhost:8080/api/v1` (local)

**Interactive Testing**: Visit [Swagger UI](/docs/swagger/) to test all endpoints directly in your browser.
